## 実際に実行した比較

1. Git blob SHA-1まで一致する、無変更の公式Pythonファイルを実行。
   ランドマークだけをC++と揃え、公式のINysと登録関数はそのまま使用。
   固定回数比較では公式のtol=-1を指定して早期停止だけを抑制し、反復式は変えません。
2. NumPy/SciPyで独立に書いた完全カーネル・明示U・直接残差のpaper-mode基準と比較。
3. C++の小規模な数学・境界条件テスト。
4. 同一ランク・同一初期値・同一反復回数のdense-E基準とstreaming-E高速版を速度比較。

そのため、区別すべき主張は次の3つです。

- **式の一致**：縮約方程式は同じ近似カーネルに対する代数的同値変形である。
- **実装の一致**：固定した基底/ランドマークと有限個の検証例で、丸め誤差の範囲で一致する。
- **論文全体の再現**：FAUST/TOSCA、全ハイパーパラメータ、全ランダム初期化、論文の表の成績は未再現。

前2つを検証したことを、最後の主張にすり替えません。
