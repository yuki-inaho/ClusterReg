# 数式・C++実装・検証の対応

## 1. 記号と対象モデル

sourceを `Y∈R^{N×d}`、targetを `X∈R^{M×d}`、行ごとに1点とします。
論文のN/Cの混用を避け、ここではsourceの点数を一貫してNとします。
`U∈R^{M×N}` で `U 1_N = 1_M`。alphaはN成分で総和1です。

対象は論文§4.3の**全クラスタ共通の等方分散** `Σ_j=σ²I` に整理したモデルです。
クラスタごとに異なる共分散、固定行列式制約付きの一般形の最適化ではありません。

論文の式(8)、(9)の係数規約に合わせて、完全カーネルの場合の目的関数を

```
J = S(U,T)/σ² + Md log(σ²)
    + λ Σ_ij U_ij log(U_ij / alpha_j)
    + ζ tr(Cᵀ K C),
S(U,T) = Σ_ij U_ij ||x_i - t_j||²,
T = Y + K C,
K_ij = exp(-γ ||y_i-y_j||_1).
```

とします。CはN×dであり、変位は各座標成分を持ちます。
`0 log 0 = 0` とする連続拡張を使います。実装ではさらに `σ²≥sigma_floor` を課します。

## 2. Uとalphaの更新

Uの1行のLagrange条件から

```
log U_ij = log alpha_j - ||x_i-t_j||²/(λσ²) + 行ごとの定数
```

となります。したがって、`l_ij=log alpha_j-||x_i-t_j||²/(λσ²)` に対して

```
m_i = max_j l_ij
U_ij = exp(l_ij-m_i) / Σ_k exp(l_ik-m_i)
alpha_j = (Σ_i U_ij) / M.
```

`Σ_j` が共通なので行列式由来の因子は正規化で相殺されます。一般の異なる共分散に
拡張する場合は `alpha_j |Σ_j|^(-1/λ)` が必要で、本文式(6)の因子をそのまま使えません。

`expectation()` のstreaming経路はU全体を保持せず、次の十分統計量を計算します。

```
w = Uᵀ1_M       [N]
P = UᵀX         [N×d]
h = Σ U log U   [scalar]
S_old = Σ U ||x_i-t_old,j||².
```

計算する組は全M×N個です。これは近似E-stepではありません。
`Statistics::mass`, `px`, `entropy`, `sse_old` が対応します。
スレッドごとに統計量を持ち、決まった順で加算します。スレッド数変更による浮動小数点の
加算順の違いは許容し、数値的に検証します。異なるCPU間のビット一致は保証しません。

## 3. 変形の更新と式(9)の次元修正

`D=diag(w)`, `G=P-DY`, `κ=ζσ²` と置くと、変位係数の正規方程式は

```
(DK + κI) C = G.                             (A)
```

Dが可逆なら

```
(K + κD^-1) C = D^-1 P - Y
```

と同値です。本文の `U1`、`UX` の箇所を、定義されたUの向きに合わせて `Uᵀ1`、`UᵀX`
へ直した形です。実装の `dense_update()` は(A)を直接解き、ゼロ質量に対してDの逆を作りません。

## 4. Nyströmの低ランクと安定な縮約解法

Elkan k-meansで得たr個のランドマークをZとし、

```
E = K(Y,Z)           [N×r]
W = K(Z,Z)           [r×r]
W = V diag(s) Vᵀ
Q = E V_kept diag(s_kept^-1/2)
K_tilde = Q Qᵀ.
```

固有値打切りがなければ `K_tilde=EW^-1Eᵀ` です。既定の絶対閾値 `1e-6` は公式と同じで、
打切りが生じた場合は一般化逆に相当する**別の追加近似**です。保持ランクを出力します。
`make_basis()` の `projection` は `V_kept diag(s_kept^-1/2)` です。

(A)のKをK_tildeに置き、`B=QᵀC` として左からQᵀをかけると

```
(QᵀDQ + κI) B = QᵀG.                       (B)
T = Y + QB.
```

Bはr×dです。κ>0なので左辺は正定値で、Choleskyで解けます。
`reduced_update()` は(B)そのものです。正則化項も

```
tr(Cᵀ K_tilde C) = ||QᵀC||_F² = ||B||_F²
```

と評価できます。逆行列の明示的形成は不要です。

公式はWoodbury式により

```
C = [G - DQ (QᵀDQ+κI)^-1 QᵀG] / κ
T = Y + Q(QᵀC)
```

を計算しています。数学的には(B)と同じですが、κが小さいとCの計算で大きな項同士の差と
除算が現れます。直接Bを解くことでこの不要な桁落ちを避けます。
これは**同じK_tildeに対する厳密な代数変形**であり、ランクをさらに落とした近似ではありません。

## 5. 分散更新、残差の安定な計算、停止

固定U・Tについて `S/σ²+Md log σ²` を微分すると

```
σ²_new = max(S(U,T_new)/(Md), sigma_floor).
```

を得ます。負のトレースを `abs()` で隠すのではなく、重み付き二乗和であることを保ちます。
Uを保存していないので、`Δ=T_new-T_old` により

```
S_new = S_old
        - 2 Σ_j Δ_j · (P_j - w_j T_old,j)
        + Σ_j w_j ||Δ_j||².
```

と計算します。最後のスカラー集約はlong doubleを用います。丸め許容範囲内の負値だけを0に戻し、
許容範囲を超える負値は例外にします。これは検証用の明示的二重和と比較しています。

paperモードは `U → alpha → B → sigma²` の順で更新し、4段階のJを記録します。
固定したQについて、各ブロックの最小化はJを増やさないことを式と数値テストで確認します。
停止は反復間のJの相対変化 `|J_new-J_old|/(1+|J_old|)`、最大反復回数、分散下限付近の
変位変化から判定します。無制約の元問題ではなく、分散下限を設けた問題です。

**これはJの大域最小化の証明ではありません。** 全変数同時では非凸で、異なる初期基底、
部分欠損、大きな変形、対称性により異なる解へ収束し得ます。

## 6. 正規化と新しい点への適用

公式C++の規約に合わせ、各点群を独立に平均0、RMS半径1にします。

```
mu_Y = mean(Y_raw)
s_Y = sqrt(Σ ||y-mu_Y||² / N)
Y = (Y_raw-mu_Y)/s_Y
```

targetも同様です。座標軸ごとの標準偏差1ではなく、分布をガウス分布に変換する処理でもありません。
半径0の点群にはscale=1を用いることを明記します。

任意の元source座標qに対して、同じ正規化と学習時の重心整列量 `delta` を使い
`q'=(q-mu_Y)/s_Y+delta` とします（独立正規化時は `delta` は丸め誤差を除いて0）。

```
T_raw(q) = mu_X + s_X [q' + K(q',Z) projection B].
```

を適用します。`transform()` は学習時の点に再適用した際の一致もテストしています。

## 7. Nyström誤差境界に関する留保

本文命題1と補足資料§2は

```
||K-EW^-1Eᵀ||_F
 ≤ 4 sqrt(2) T^(3/2) γ sqrt(r q) + 2 r γ² T q ||W^-1||_F
```

を提示します。小さな実例で左辺・右辺を計算していますが、**実例で成立しても定理の証明にはなりません**。
また、Wの固有値を打ち切ったケースは、記載の逆行列W^-1の定理の前提と分けて扱う必要があります。

補足資料p.2の証明には、L1距離からL2量子化誤差へ移る際の次元係数の問題があります。
L2で評価する安全な一般的評価は

```
|K(a,b)-K(c,d)|²
 ≤ 2 d γ² (||a-c||_2² + ||b-d||_2²)
```

です。導出は `|e^-u-e^-v|≤|u-v|`、逆三角不等式、
`||v||_1≤sqrt(d)||v||_2`、`(A+B)²≤2(A²+B²)` から従います。

実際、`a=b=0`, `c=h 1_d`, `d_point=-h 1_d` では、左辺を
`2γ²(||a-c||_2²+||b-d_point||_2²)` で割った比はh→0でdに近づきます。
d=3, gamma=2, h=1e-6のテストでは約2.999964で、次元なしの中間評価では足りません。
これは**印刷された最終の誤差境界そのものに対する反例とは主張していません**。
補足の証明をそのまま一般次元の保証として採用しない、という留保です。
